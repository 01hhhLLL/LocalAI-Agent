# LocalAI Agent v0.1.1 ? Windows x64 developer preview

Main contributor and project lead: [@01hhhLLL](https://github.com/01hhhLLL).

[Download the Windows installer](LocalAI-Agent-v0.1.1-win-x64.exe). Double-click it, choose an empty installation folder, then review the hardware and dependency report. The installer copies the reviewed voice/application source and creates shortcuts.

This preview does **not** bundle or install Python runtimes, Hermes, local model weights, or API credentials. A fresh Windows PC will need those components before the voice hotkey works. The visual API key is optional and supplied by each user. The installer is unsigned and has not been validated on a clean second PC.

Included source is the [reviewed voice/application snapshot](../snapshots/verified-voice-2026-10-25/README.md). In-progress music work, tests, logs, local data, models and secrets are excluded. Installer build sources are in [versions/v0.1.1/installer](../versions/v0.1.1/installer). To reproduce the build, place that installer directory next to the reviewed snapshot source in a clean Git checkout, then run `installer/build-release.ps1` with Python and .NET 8 SDK.
