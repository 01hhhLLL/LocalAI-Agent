# Contributing

The primary maintainer of this repository is [01hhhLLL](https://github.com/01hhhLLL). Contributions are welcome through issues and pull requests.

Before proposing a change, describe what it does, why it is needed, how it was checked, and which files or components changed. Keep unrelated changes separate. If you distribute a modified version, include prominent notices that you changed the work and give the relevant date, as required by GPLv3 section 5(a). Preserve existing copyright and license notices. The Git commit history and pull-request diff show the exact changed files; GPLv3 does not require a detailed per-line change log.

Do not include personal credentials, model weights, recordings, runtime logs, or local machine configuration in contributions. Test with your own credentials and describe any environment-dependent limitations.

The Windows installer is a developer preview. It does not bundle Hermes, local model weights, or a user's API key, and it has not yet been validated on a second clean computer. State this boundary when reporting installation or runtime results.

Third-party components and assets retain their own licenses. Check their terms before adding or redistributing them.
