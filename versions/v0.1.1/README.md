# LocalAI Agent v0.1.1 for Windows (developer preview)

Project lead and main contributor: [@01hhhLLL](https://github.com/01hhhLLL).

This is a downloadable Windows x64 installer for the reviewed voice/application
source snapshot. Run the installer, choose an empty destination folder, and
review its hardware and dependency report. The installer copies the bundled
source and creates shortcuts. It does not bundle or automatically install model
weights, Python environments, Hermes, or private API credentials. On a fresh
computer, the voice hotkey cannot run until those prerequisites are supplied.

Included capabilities are the hotkey UI, local speech transcription entry,
transcript review, approved application/alias lookup, candidate correction,
bounded task execution, local OCR, and optional visual location. Selected
real-machine checks exist for this line, but arbitrary desktop tasks, noisy
speech, fresh-PC operation, and visual API fallback are not certified.
The separate in-progress music expansion and uncommitted changes are excluded.

The installer is unsigned. Windows may show an unknown-publisher warning.
Use the SHA256 value in the published release note to verify the downloaded
file. The matching source snapshot and its file hashes are in this repository.

Version: 0.1.1
Platform: Windows x64
Release channel: developer preview
